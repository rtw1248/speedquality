# v1.5.1 发布说明

修复部分 IPv6 和旧节点仍显示城市加长编号、没有固定名称的问题。

- 有城市信息且没有明确归属冲突的节点，可以在归属核验尚未完成时登记固定名称。IP 查询服务暂时不可用，不再阻塞这些节点的命名。
- 后台独立批量补齐已有节点名称，无需重新测速，也无需为命名重新查询 IP 服务。
- 名称仍按完整节点编号和 IP 类型固定对应，不覆盖已登记名称。归属核验状态、测速成功时间和地图点亮条件保持原有判定。
- 历史网页报告在准确匹配登记记录后自动补充名称；已经输出到终端的旧文本不会改变。
- 补充编号说明：IPv4、IPv6分别编号，跨IP类型同名不代表同一台服务器，对比时需同时确认IP类型和节点名称。

本次无需新增数据库迁移。已补充 IPv6 查询结果不完整时的命名回归，以及旧节点批量补名不改变覆盖状态和测速记录的检查。
