# v1.3.0发布说明

## 用户可见变化

- 为现有终端、网页、复制文本、NodeSeek、Markdown和报告链接预览图补充实际测速节点的城市、稳定编号和来源。未知城市不代填，连接失败的候选节点不显示为已使用。
- 新增`/nodes`节点地图，可按运营商、IP协议和来源查看近期验证覆盖，并从页面进入贡献节点说明。私有节点不展示，教育网标注为建设中。
- 自建节点支持教育网，含IPv6单独接入。教育网仅通过Route Key定向测试，公共教育网测速继续关闭。
- 安装向导简化重复输入，解释运营商、访问模式和更新方式。新节点默认200Mbps、5并发、每日总额度100GB；保留并发0、每日公共额度10GB。已有配置保留原值。
- 平台独立核验注册地址的地区和运营商，海外地址不能靠手填国内省份注册。IPv4和IPv6归属不同会要求选择网络。
- README精简，完整参数和细节移至`docs/usage.md`。

联合报告分页、复制导出和报告链接预览图均为已有功能。本次验收重点是节点地图、新增节点信息、自建教育网接入、安装流程和文档；原有分页顺序等属于兼容性回归检查。

已确认不开发“Markdown＋图片”论坛导出功能。

## 兼容与数据

租约只向带`X-SQ-Node-Info: 1`能力头的客户端增加节点快照，旧版严格JSON解析保持兼容。
新程序可接受旧平台不含快照的租约。节点快照经平台签名、上报时校验，报告不保存签名；
不为这一功能新增保存测速用户完整IP。原有NQ分页顺序保持不变。

Core迁移0006扩展教育网运营商和覆盖目录，保留节点身份、密钥哈希、额度、流量和活动租约。
地图基于新版本上线后逐步积累的实际观察；历史报告不补造城市，地图空白不代表某省没有节点。

## 发布顺序与回退

1. 备份Core数据库，应用0006迁移，先部署兼容旧客户端的新Core。公共Worker无需新增数据库迁移。
2. 构建并发布签名的v1.3.0探针与sq-node二进制、清单及校验文件，确认amd64、arm64资产齐全。
3. 部署公开Worker，将`GITHUB_REF`和`PROBE_VERSION`设为`v1.3.0`，验证`/run`、`/nodes`及报告。
4. GitHub原始脚本与发行版应同步交付，避免`main`脚本先引用尚不存在的v1.3.0二进制。

回退时可先恢复旧Worker与脚本版本，新Core仍兼容旧探针；保留0006表结构。
不要在已有教育网节点时直接恢复旧Core调度代码，也不要逆向删除新表或重写已发布迁移。
如需完全回退Core，先停止新任务并按备份恢复流程处理，避免丢失新注册节点和流量记账。
