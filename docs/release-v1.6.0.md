# v1.6.0 发布说明

## 重传率

- 在“延迟、重传率、单线程上传、单线程下载、节点”的顺序中展示上传 TCP 重传百分比。
- 以实际上传连接在正式测量窗口内的重传字节 / 总发送字节（含重传）计算，不增加探测请求，
  不要求测速节点增加接口，也不使用全机计数。不包含预热和结束清理。
- 计数不可用或上传失败显示 `—`，微量非零重传显示 `<0.01%`。旧结果没有计数时不补零。
- 低于1%绿色、1%至不足5%橙色、达到5%红色；不可用时灰色，终端、网页和彩色导出一致。
- 计算口径写入 README 与使用文档，页面不新增说明弹窗。此指标不等于双向丢包率。

## 两次 SQ 对照

- `--sq URL` 只能关联一份历史 SQ，与本次合计两份；不支持重复参数或对已有两份SQ继续叠加。
- 链接、数量和出口身份在下载测速程序和申请节点前检查，失败时提示测速尚未开始。
- 网页保留一个“速度质量”分页，在其中切换两份结果；按北京时间的一天内时刻排列，保留日期。
- 原始报告不修改、不复制、不续期。历史报告过期后显示不可用，本次结果仍保留。
- 历史 SQ 自带 NQ 与本次 `--nq` 去重并逐份校验身份，选距本次实际检测时间最近的一份。
  时间差相同时优先显式 `--nq`，已知时间优先。导出保留一份NQ和按时刻排列的两份SQ。
- 帮助、运行提示和网页指南写明 SQ 上限及 NQ 身份校验、最近时间选择规则。

## 升级

GitHub 入口与平台入口统一使用 `v1.6.0` 探针。
先准备签名二进制，再应用公开 Worker 的 `0005_sq_report_link.sql` 迁移，最后切换 Worker 和客户端入口。
VPS 部署沿用自动迁移。探针结果协议保持版本1，重传计数为可选字段，旧客户端仍可测速。
SQ 关联需要稳定的 `RATE_LIMIT_SALT`；报告只保存带密钥的出口身份摘要，不新增完整IP存储。
旧报告缺少该摘要，不能回填或凭脱敏网段自动关联。密钥轮换后旧摘要可能无法再匹配。

校验范围是出口身份；共享NAT无法据此区分同一出口后的不同VPS。
