# v1.6.2 发布说明

修复 NQ 身份不匹配或无法校验时，测速结束后分享报告返回 HTTP 500 的问题。此前应用接收了拒绝关联状态，但数据库约束没有同步，导致 SQ 结果无法保存；现在独立 SQ 和通过 `--sq` 关联的两份结果均可正常保存，并保留 NQ 拒绝原因。

NodeSeek / 烧饼论坛彩色导出使用独立的紧凑排版：减少列间空白，常见城市的完整节点名称与测速结果保持同行；过长的关联校验说明按显示宽度主动分行，避免论坛截断。极长节点名称通过表内引用对应到表后完整名称，不截断身份信息。NQ 原始分页、内容与颜色继续保留。

部署前应用公开 Worker 的 `0006_rejected_nq_reports.sql` 迁移。迁移在事务中复制既有报告并更新状态约束，保留所有原字段、身份摘要、SQ 关联、有效期及过期索引。VPS 部署会自动执行迁移；回退 Worker 时保留此兼容扩展。

验证覆盖真实 SQLite 的失败复现、独立/关联 SQ 的两种 NQ 拒绝状态、已有报告完整迁移、论坛长说明与长节点名称，以及旧报告导出。
