# v1.3.2发布说明

节点城市直接显示名称，去掉“（来源标注）”，例如：

```text
节点：武汉 · 4d83ee8591e3 · 第三方
```

终端、网页报告、复制文本、NodeSeek、Markdown和节点地图统一采用简洁显示。城市缺失或归属冲突时仍显示“城市未知”或“城市待核实”。城市来源、校验记录和地图点亮条件保持原有规则。

节点地图明确说明第三方与公开自建节点均参与统计，区分“已收录”和“已点亮”，并在节点详情显示未点亮的原因，例如地区和运营商待核验、核验过期或最近一次测速未成功。测速成功仍需有效的独立归属核验才能计入覆盖。

本版本包含[v1.3.0](release-v1.3.0.md)的节点信息、节点地图和自建节点优化，以及[v1.3.1](release-v1.3.1.md)的地图加载修复。公共教育网测速暂未开放；自建教育网节点可通过Route Key定向使用。
